## Staticfile CDN
[https://staticfile.org/](https://staticfile.org/)

CDN加速由七牛云提供，技术社区掘金支持。
我们提供这样一个仓库，让它尽可能全面收录优秀的开源库，并免费为之提供 CDN 加速服务，使之有更好的访问速度和稳定的环境。同时，我们也提供开源库源接入的入口，让所有人都可以提交开源库，包括 JS、CSS、image 和 swf 等静态文件。

## UNPKG
[https://unpkg.com/](https://unpkg.com/)

UNPKG是一个快速的全球内容交付网络，适用于NPM上的所有内容。使用它可以使用 URL 快速轻松地从任何包加载任何文件
```
unpkg.com/:package@:version/:file
```
## elemecdn
用来替代UNPKG，相当于它的国内镜像，速度很快，而且可以加载npm上的所有文件。

## BootCDN
[https://www.bootcdn.cn/](https://www.bootcdn.cn/)

BootCDN 是 极兔云 联合 Bootstrap 中文网 共同支持并维护的前端开源项目免费 CDN 服务，致力于为 Bootstrap、jQuery、React、Vue.js 一样优秀的前端开源项目提供稳定、快速的免费 CDN 加速服务。
