## 机器学习
> 一系列 ML 模型、深度学习和神经网络库。
- [Tensorflow-iOS](https://github.com/tensorflow/tensorflow/tree/master/tensorflow/examples/ios) - Google 官方构建的强大神经网络库的 iOS 移植版。
- [CoreML-Models](https://github.com/likedan/Awesome-CoreML-Models) - 一组独特的 Core ML 模型。
- [Swift-AI](https://github.com/Swift-AI/Swift-AI) - Swift 机器学习库。
- [off-grid-mobile](https://github.com/alichherawalla/off-grid-mobile) - 完全在设备上运行 LLM、视觉模型和 Stable Diffusion。无需互联网，数据不离开手机。支持 React Native，兼容 iOS 和 Android。MIT 许可证。
- [Bender](https://github.com/xmartlabs/Bender) - 轻松构建快速神经网络。使用 TensorFlow 模型。底层基于 Metal。
- [AIToolbox](https://github.com/KevinCoble/AIToolbox) - 一个用 Swift 编写的 AI 模块工具箱：图/树、线性回归、支持向量机、神经网络、PCA、KMeans、遗传算法、MDP、高斯混合模型。
- [Swift-Brain](https://github.com/vlall/Swift-Brain) - 面向未来 iOS 开发的人工智能/机器学习数据结构和 Swift 算法。贝叶斯定理、神经网络等 AI 内容。
- [TensorSwift](https://github.com/qoncept/TensorSwift) - 一个用于在 Swift 中计算张量的轻量级库，其 API 与 TensorFlow 类似。
- [iOS-GenAI-Sampler](https://github.com/shu223/iOS-GenAI-Sampler) - 一组 iOS 上的生成式 AI 示例。
- [SwiftCoreMLTools](https://github.com/JacopoMangiavacchi/SwiftCoreMLTools) - 一个用于在 Swift 中创建和导出 CoreML 模型的 Swift 库。
- [DL4S](https://github.com/palle-k/DL4S) - Swift 的深度学习：针对所有可运行 Swift 的设备，基于反向模式自动微分实现加速的张量运算和动态神经网络。

## 网络
> HTTP 客户端、套接字库、可达性助手和网络实用工具。
- [Alamofire](https://github.com/Alamofire/Alamofire) - Alamofire 是一个用 Swift 编写的 HTTP 网络库，由 AFNetworking 的创建者开发。

- [YTKNetwork](https://github.com/yuantiku/YTKNetwork) - YTKNetwork 是一个基于 AFNetworking 的高层请求工具。
- [ASIHTTPRequest](https://github.com/pokeb/asi-http-request) - 易于使用的 CFNetwork 封装，用于 HTTP 请求，支持 Objective-C、macOS 和 iPhone。
- [RealReachability](https://github.com/dustturtle/RealReachability) - 我们需要观察真实的网络可达性。这正是RealReachability所做的。
- [Tiercel](https://github.com/Danie1s/Tiercel) - 纯 Swift iOS 下载框架，支持后台下载、重启恢复、可续传传输和任务管理。
- [MonkeyKing](https://github.com/nixzhu/MonkeyKing) - MonkeyKing 帮助你将消息发布到中国社交网络。
- [Siesta](https://github.com/bustoutsolutions/siesta) - 对RESTful资源的优雅抽象，解开有状态混乱。基于回调和委托的网络编程的替代方案。

- [ResponseDetective](https://github.com/netguru/ResponseDetective) - 网络层的福尔摩斯。
- [SwiftHTTP](https://github.com/daltoniam/SwiftHTTP) - Swift中NSURLSession的轻量封装。简化HTTP请求。
- [Networking](https://github.com/3lvis/Networking) - Swift 中的简单 HTTP 网络，一个支持图像缓存的 NSURLSession 包装器。
- [Overcoat](https://github.com/Overcoat/Overcoat) - 小巧但功能强大的库，让创建 REST 客户端变得简单而有趣。
- [Get](https://github.com/kean/Get) - 一个使用 async/await 构建的现代 Swift Web API 客户端。
- [XMNetworking](https://github.com/kangzubin/XMNetworking) - 一个轻量但强大的网络库，基于 AFNetworking，语法简洁且富有表现力。
- [Pitaya](https://github.com/johnlui/Pitaya) - 一个Swift HTTP/HTTPS网络库，恰好能在机器上执行。
- [EVCloudKitDao](https://github.com/evermeer/EVCloudKitDao) - 简化对 Apple CloudKit 的访问。
