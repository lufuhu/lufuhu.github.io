## 开发
> 在基础层面增强开发过程。

- [HotswapAgent](https://github.com/HotswapProjects/HotswapAgent) - 无限制的运行时类和资源重定义。

## 序列化

- [iCal4j](https://github.com/ical4j/ical4j) - 解析和构建 iCalendar [RFC 5545](https://tools.ietf.org/html/rfc5545) 数据模型。
- [Time4J](https://github.com/MenoData/Time4J) - 高级日期和时间库。
- [ThreeTen-Extra](https://github.com/ThreeTen/threeten-extra) - 补充 JDK 8 中日期时间类的附加类。
- [Jollyday](https://github.com/focus-shift/jollyday) - 确定给定年份、国家/名称以及可能的州/地区的节假日。
:::

::: masonry
## API 兼容性
> 用于跟踪 API 演进并检测库版本之间破坏性变更的工具。
- [japicmp](https://github.com/siom79/japicmp) - 比较两个库 JAR 并报告源码级和二进制级不兼容变更。
- [Revapi](https://github.com/revapi/revapi) - 可扩展的 API 分析与变更跟踪，支持可配置的源码、二进制和语义兼容性检查。
- [Roseau](https://github.com/alien-tools/roseau) - 通过比较 JAR 文件或源代码中的库版本，检测源码级和二进制级破坏性变更。
:::

::: masonry
## CSV
> 简化 CSV 数据读写的框架和库。
- [FastCSV](https://github.com/osiegmar/FastCSV) - 性能优化、无依赖且符合 RFC 4180。
- [jackson-dataformat-csv](https://github.com/FasterXML/jackson-dataformats-text) - 用于读写 CSV 的 Jackson 扩展。
- [opencsv](https://opencsv.sourceforge.net) - 简单的 CSV 解析器。
:::

::: masonry
## 平面文件
> 用于读写定长和分隔平面文件的框架和库。
- [BeanIO](https://github.com/beanio/beanio) - 使用 XML 或注解配置，将定长或分隔记录的平面文件与 Java Bean 相互映射。
- [Flatpack](https://github.com/Appendium/flatpack) - 解析和写入分隔及定长平面文件，支持可选的列映射定义。
- [fixedformat4j](https://github.com/jeyben/fixedformat4j) - 基于注解的定宽平面文件与 POJO 和 Java record 之间的映射。
:::

::: masonry
