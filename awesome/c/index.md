## 源码集合
> 小型源码集合。如果你想要大型且集成的项目，请查看
- [stb](https://github.com/nothings/stb) - 一系列单文件库。公有领域。
- [clib](https://github.com/clibs/clib) - 类似包管理器。自带[一批自己的库][27]。
- [tinyheaders](https://github.com/RandyGaul/tinyheaders) - 仅头文件库集合，主要面向游戏开发。
- [mmx](https://github.com/vurtun/mmx) - 单头文件库集合。多种许可证，均为开源。
- [zpl](https://github.com/zpl-c/zpl) - C99 跨平台仅头文件库，包含许多实用功能。
- [par](https://github.com/prideout/par) - 一批单文件库。
- [Snippets](https://github.com/DanielGibson/Snippets/) - 有用的代码片段和仅头文件库。公有领域。
- [CCAN](http://ccodearchive.net/) - 仿照 Perl 的 CPAN 设计，这是一个包含各种功能代码的大型集合。完整列表见[此处][104]。多种许可证，均为开源。
- [gnulib](https://www.gnu.org/software/gnulib/) - 常见 GNU 代码集合。多种许可证，均为开源。
- [libdjb](http://www.fefe.de/djb/) - 实现各种功能的库集合。（据称）属于公有领域。
:::

## 文本编辑器扩展
> 虽然几乎所有像样的程序员文本编辑器都支持 C，但仍有一些
- [YouCompleteMe](https://github.com/ycm-core/YouCompleteMe) - Vim 的代码补全引擎。
- [Syntastic](https://github.com/vim-syntastic/syntastic) - Vim 的语法检查和 lint 工具。
- [Neomake](https://github.com/neomake/neomake) - Neovim/Vim 的异步 :make 和 lint 框架。
- [Flycheck](https://github.com/flycheck/flycheck) - Emacs 的现代语法检查。对于 C，可使用 GCC 或 Clang 作为后端。
- [CCompletion](http://freeweb.siol.net/rmihor/NppCCompletionPlugin.zip) - Notepad++ 自动补全插件。适用于 Ctags 识别的所有标识符。此为下载链接。
- [CEDET](http://cedet.sourceforge.net/) - Emacs 开发环境工具集；旨在为 Emacs 提供类似 IDE 的功能。内置。
- [YASnippet](http://joaotavora.github.io/yasnippet/) - Emacs 代码模板系统，包含常见代码片段的 C 模板。
:::

## 压缩

- [heatshrink](https://github.com/atomicobject/heatshrink) - 面向嵌入式与实时系统的数据压缩/解压缩库。
- [FiniteStateEntropy](https://github.com/Cyan4973/FiniteStateEntropy) - 两种针对现代 CPU 优化的高效压缩编解码器。
- [smaz](https://github.com/antirez/smaz) - 高效字符串压缩库。
- [DENSITY](https://github.com/centaurean/density) - 超快压缩库。
- [TurboPFor](https://github.com/powturbo/TurboPFor) - 最快的整数压缩。
- [pixz](https://github.com/vasi/pixz) - 并行、索引式 xz 压缩器。
- [Lizard](https://github.com/inikep/lizard) - 原为 LZ5；一种解压速度极快的高效压缩器。在 1000MB/s 及更快的解压速度下，压缩比可与 zip 和 zlib 相媲美。
- [fastLZ](https://github.com/ariya/fastlz) - 极速无损压缩库（LZ77 类型）。可嵌入 ARM Cortex-M 等小型目标平台。源码可直接嵌入项目（一对 h/c 文件），无需动态内存分配。
- [SIMDComp](https://github.com/lemire/simdcomp) - 使用二进制打包压缩整数列表的简单库。在 x86 上利用 SIMD 指令。
- [squash](https://github.com/quixdb/squash) - 压缩抽象库，附带一些实用工具。
- [libzip](https://github.com/maxim2266/str) - 用于读取、创建和修改 zip 归档的 C 库。
- [TurboRLE](https://github.com/powturbo/TurboRLE) - 最高效的游程编码。
- [fast\_zlib](https://github.com/gildor2/fast_zlib) - 改进版 zlib，运行速度快 2 至 10 倍。
- [huffandpuff](https://github.com/adamierymenko/huffandpuff) - 极简 Huffman 编码器与解码器。公有领域。
- [zlib-ng](https://github.com/Dead2/zlib-ng) - 针对“下一代”系统优化的 zlib 替代品。
- [blosc](http://blosc.org/pages/blosc-in-depth) - 极快、多线程的元压缩器库。多种许可证，均为开源。
- [clzip](http://lzip.nongnu.org/clzip.html) - 高质量数据压缩器 [Lzip][433] 的 C 版本（LZMA 实现）。
- [libbzip2](http://www.bzip.org/) - 无专利、高质量的数据压缩库。
- [lz4](http://lz4.github.io/lz4/) - 用于极速压缩算法的库。
- [lzo](http://www.oberhumer.com/opensource/lzo/) - 快速数据压缩库。
- [shoco](http://ed-von-schleck.github.io/shoco) - 用于小型文本字符串的压缩器。
- [Zlib](http://zlib.net) - 极其出色却又细致低调的压缩库。

## 工具
> 帮助编写和调试 C 代码的有用程序（非编辑器），
- [address-sanitizer](https://github.com/google/sanitizers) - 快速内存错误检测器。
- [include-what-you-use](https://github.com/include-what-you-use/include-what-you-use) - 帮助查找不必要的包含并提出修复建议。基于 LLVM/Clang（且仅适用于它）。
- [c](https://github.com/ryanmjacobs/c) - 在命令行中一步编译并执行 C "脚本"。也支持 shebang。
- [incbin](https://github.com/graphitemaster/incbin) - 轻松将二进制文件包含到 C/C++ 应用程序中
- [SMACK](https://github.com/smackers/smack) - 模块化软件验证工具链及独立软件验证器。目前仅适用于使用 Clang 编译的程序。
- [c99sh](https://github.com/RhysU/c99sh) - 使用 hash-bang 运行 C 文件。
- [Artistic Style](http://astyle.sourceforge.net/) - 快速且小巧的自动源代码格式化工具，支持 C。
