## Web 框架
- [Next.js](https://github.com/vercel/next.js) - 用于服务端渲染的通用 JavaScript Web 应用的极简框架。
- [Nest](https://github.com/nestjs/nest) - 受 Angular 启发的框架，用于构建高效且可扩展的服务端应用。
- [Express](https://github.com/expressjs/express) - Web 应用框架，提供强大的功能集，用于构建单页、多页和混合 Web 应用。
- [Nuxt.js](https://github.com/nuxt/nuxt.js) - 用于服务端渲染的 Vue.js 应用的极简框架。
- [Meteor](https://github.com/meteor/meteor) - 一个超简单、数据库无处不在、数据在线传输的纯 JavaScript Web 框架。*（你可能喜欢 [awesome-meteor](https://github.com/Urigo/awesome-meteor)）*
- [Fastify](https://github.com/fastify/fastify) - 快速且低开销的 Web 框架。
- [Koa](https://github.com/koajs/koa) - 由 Express 团队设计的框架，旨在为 Web 应用和 API 提供更小、更具表现力且更健壮的基础。
- [Hono](https://github.com/honojs/hono) - 小巧且快速的 Web 框架。
- [AdonisJs](https://github.com/adonisjs/core) - 基于依赖注入和 IoC 容器坚实基础的真正 MVC 框架，适用于 Node.js。
- [Feathers](https://github.com/feathersjs/feathers) - 以 Express 精神构建的微服务框架。
- [Hapi](https://github.com/hapijs/hapi) - 用于构建应用程序和服务的框架。
- [Restify](https://github.com/restify/node-restify) - 使您能够构建正确的 REST Web 服务。
- [Micro](https://github.com/vercel/micro) - 采用异步方法的极简微服务框架。
- [TypeGraphQL](https://github.com/MichalLytek/type-graphql) - 使用 TypeScript、类和装饰器创建 GraphQL API 的现代框架。
- [Moleculer](https://github.com/moleculerjs/moleculer) - 快速且强大的微服务框架。
- [ThinkJS](https://github.com/thinkjs/thinkjs) - 支持 ES2015+、WebSockets、REST API 的框架。
- [LoopBack](https://github.com/loopbackio/loopback-next) - 用于创建 REST API 并轻松连接后端数据源的强大框架。
- [seneca](https://github.com/senecajs/seneca) - 用于编写微服务的工具包。
- [Ts.ED](https://github.com/tsedio/tsed) - 用于在 Express.js 或 Koa.js 之上构建服务端应用的直观 TypeScript 框架。
- [Tinyhttp](https://github.com/tinyhttp/tinyhttp) - 现代且快速的类似 Express 的 Web 框架。
- [ActionHero](https://github.com/actionhero/actionhero) - 用于为 TCP 套接字、WebSockets 和 HTTP 客户端构建可重用和可扩展 API 的框架。
- [Lad](https://github.com/ladjs/lad) - 由前 Express TC 和 Koa 成员打造的框架，集成了 Web、API、任务和代理服务器。
- [Marble.js](https://github.com/marblejs/marble) - 基于 TypeScript 和 RxJS 的用于构建服务端应用的函数式响应式框架。
:::

- [get-stream](https://github.com/sindresorhus/get-stream) - 将流作为字符串或缓冲区获取。
- [byline](https://github.com/jahewson/node-byline) - 超简单的逐行流读取器。
- [multistream](https://github.com/feross/multistream) - 将多个流合并为单个流。
- [pumpify](https://github.com/mafintosh/pumpify) - 将一组流组合成单个双工流。
- [into-stream](https://github.com/sindresorhus/into-stream) - 将缓冲区/字符串/数组/对象转换为流。
- [duplexify](https://github.com/mafintosh/duplexify) - 将可写和可读流转换为单个 streams2 双工流。
- [from2](https://github.com/hughsk/from2) - 受 `through2` 启发的 ReadableStream 便捷包装器。
- [binary-split](https://github.com/maxogden/binary-split) - 换行符（或任意分隔符）分割流。
- [through2-concurrent](https://github.com/almost/through2-concurrent) - 并发转换对象流。
- [peek-stream](https://github.com/mafintosh/peek-stream) - 转换流，允许在决定如何解析之前先查看第一行。
- [first-chunk-stream](https://github.com/sindresorhus/first-chunk-stream) - 转换流中的第一个数据块。
- [pad-stream](https://github.com/sindresorhus/pad-stream) - 填充流中的每一行。
:::
